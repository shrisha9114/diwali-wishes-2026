# Simple Diwali Wishes

A simple personalized Diwali greeting page:
1. The visitor enters their name.
2. A festive popup says "Happy Diwali, [name]!"
3. Fireworks animate in the background.

## Run
- Extract the ZIP.
- Open this folder in VS Code.
- Open `index.html` with Live Server, or open it directly in a modern browser.
- Deploy the folder to GitHub Pages, Netlify, or Vercel to share a public link.

No build tools or JavaScript libraries are required. Google Fonts are optional; a system font fallback is included.
